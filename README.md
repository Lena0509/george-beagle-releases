# 乔拉比格桌宠

一只冷脸、爱被夸，偶尔会 werwerwerwer 的桌面小拉。

以 George Russell 赛车元素和比格犬二创形象为灵感，陪你工作、学习，也陪你关注比赛。

## 下载与使用

**推荐下载** · [GitHub Releases](https://github.com/Lena0509/george-beagle-releases/releases)

打开最新版本，在 **Assets** 里按系统选 ZIP 完整包。`Source code (zip)` 是 GitHub 自动生成的仓库归档。

### Windows 10 / 11

1. 下载文件名含 **Windows** 的 ZIP 完整包。
2. 右键 ZIP，选择「全部解压」。
3. 打开解压后的文件夹，双击 `GeorgeBeagle.exe`。

Windows 版需要 .NET Framework 4.8。

### Mac · 苹果 M 系列芯片

适用于 **macOS 13 或更新版本**。

1. 下载 `GeorgeBeagle-Mac-arm64-v1.1.0.zip`，双击解压。
2. 把「乔拉比格.app」拖进「应用程序」。
3. 双击「乔拉比格」打开。

Mac 版尚未经过 Apple 公证，首次打开时系统可能提示无法验证开发者。

两个版本均无需安装 Python 或 Node.js。

备用下载 · [Gitee 发行版](https://gitee.com/elena63/george-beagle-releases/releases) · [夸克网盘](https://pan.quark.cn/s/0c44a3624f6f?pwd=a9a7)（提取码 `a9a7`）

## 可以和小拉做什么

- **桌面互动**：摸摸、喂食、睡觉、拖动、T-pose、柚子叶和冠军庆祝
- **衣橱换装**：帽子、头盔、赛车服、短袖、卫衣与外套分别搭配，手里是否拿蓝帽也可以选择
- **小拉的车库**：选择历年赛车及部分特殊涂装，车辆显示可单独开关
- **今日三件事**：记下当天想完成的三件事，自动保存，完成后打勾
- **专注一圈**：调整专注与休息时长，让小拉陪你完成一圈
- **小拉的口袋**：收集和使用小饼干、奖杯与陪伴中的纪念品
- **陪伴日记**：留下心情、留言、穿搭和陪伴记录，也可以导出日记
- **比赛周末**：查看赛程与倒计时，设置赛前提醒，为每站保存应援穿搭
- **皇帝纪事**：通过「赛道纪年」与「起居注」回看乔拉的故事、采访、报道与官方影像
- **官方链接**：打开乔拉的官网、社媒和 GR63 Academy 网站

换装用于指人站姿；触发互动时会切换到对应姿态，结束后回到已选搭配。

## 常用操作

| 操作 | 功能 |
| --- | --- |
| 单击小拉 | 摸摸，切换 Bling 大眼 |
| 双击小拉 | T-pose／光翼展开 |
| 按住并拖动 | 移动小拉，爪爪扑腾 |
| 原地长按约 0.65 秒 | 柚子叶动作 |
| 快速连续点击四次 | werwerwerwer 碎碎念 |
| 右击小拉 | 打开动作菜单、围场或退出 |
| Windows 同时按住 `Shift + G + R` | 隐身，再按一次召回 |
| Mac 按 `⌘ + Shift + G` | 隐身，再按一次召回 |

关闭围场右上角的 **×** 只收起面板，小拉仍会留在桌面。

可以从 Windows 托盘或 Mac 顶部菜单栏的彩色 **63** 图标重新打开围场。需要完全关闭时，选择 **退出桌宠**。

## 更新与记录

应用内更新入口：**偏好设置 → 应用更新 → 检查更新**。

对应平台的新版上线后，即可在应用内检查更新。也可以从 GitHub Releases 手动下载对应系统的 ZIP。

日记、任务、收藏、穿搭和自定义台词保存在本地，可以在 **偏好设置 → 打开记录文件夹** 找到。备份时先退出桌宠，再复制整个记录文件夹。

| 系统 | 记录位置 |
| --- | --- |
| Windows | `%LOCALAPPDATA%\GeorgeBeagle\UserData\` |
| Mac | `~/Library/Application Support/GeorgeBeagle/UserData/` |

同一台电脑、同一个系统账户下，更新或移动程序后会继续读取已有记录。

从旧内部版本升级时，可将新版程序放回旧文件夹运行一次，自动复制旧记录；也可以在 **偏好设置 → 导入旧版记录** 中选择旧文件夹。手动导入前会自动备份当前记录。

要把 Windows 记录带到 Mac，先复制整个记录文件夹，再在 Mac 版选择 **偏好设置 → 导入 Windows / 旧版记录**。导入前会自动备份 Mac 上已有的记录。两边之后各自保存。

赛前提醒需要桌宠保持运行，隐身时不会弹出提醒。查看在线文章、视频或更新赛历需要网络；临时赛程调整请以官方信息为准。
