# 乔拉比格桌宠

一只冷脸、爱被夸，偶尔会 werwerwerwer 的 Windows 桌宠。

以 George Russell 赛车元素和暹罗厘普比格犬二创形象为灵感，陪你工作、学习，也陪你关注比赛。

## 下载与使用

**推荐下载：**  [GitHub Releases](https://github.com/Lena0509/george-beagle-releases/releases) 

备用入口：[Gitee 发行版](https://gitee.com/elena63/george-beagle-releases/releases) · [夸克网盘 · 乔拉比格桌宠](https://pan.quark.cn/s/0c44a3624f6f?pwd=a9a7)
**提取码：`a9a7`**

首次使用请选择文件名中含 **Windows** 的 **ZIP 完整包**。

1. 打开下载链接，将 ZIP 压缩包下载到 Windows 电脑
2. 右键 ZIP，选择「全部解压」
3. 打开解压后的文件夹，双击 `GeorgeBeagle.exe`

请完整解压后再运行，不要直接在压缩包内打开程序。

**运行环境：** Windows 10 / 11、.NET Framework 4.8；无需安装 Python 或 Node.js。

## 可以和小拉做什么

- **桌面互动**：摸摸、喂食、睡觉、拖动、T-pose、柚子叶和冠军庆祝
- **衣橱换装**：帽子、头盔、赛车服、短袖、卫衣与外套分别搭配，手里是否拿蓝帽也可以选择
- **小拉的车库**：选择历年赛车及部分特殊涂装，车辆显示可单独开关
- **今日三件事**：记下当天想完成的三件事，自动保存，完成后打勾
- **专注一圈**：调整专注与休息时长，让小拉陪你完成一圈
- **小拉的口袋**：收集和使用小饼干、奖杯与陪伴中的纪念品
- **陪伴日记**：留下心情、留言、穿搭和陪伴记录，也可以导出日记
- **比赛周末**：查看赛程与倒计时，设置赛前提醒，为每站保存应援穿搭
- **皇帝纪事**：通过「赛道纪年」与「起居注」回看乔拉的故事、采访、报道与官方影像
- **官方链接**：打开乔拉的官网、社媒和 GR63 Academy 网站

换装用于指人站姿；触发互动时会切换到对应姿态，结束后回到已选搭配。

## 常用操作

| 操作 | 功能 |
| --- | --- |
| 单击小拉 | 摸摸，切换 Bling 大眼 |
| 双击小拉 | T-pose／光翼展开 |
| 按住并拖动 | 移动小拉，爪爪扑腾 |
| 原地长按约 0.65 秒 | 柚子叶动作 |
| 快速连续点击四次 | werwerwerwer 碎碎念 |
| 右击小拉 | 打开动作菜单、围场或退出 |
| 同时按住 Shift + G + R | 隐身，再按一次召回 |

关闭围场右上角的 **×** 只收起面板，小拉仍会留在桌面。

需要完全关闭时，在小拉右键菜单或托盘菜单中选择 **退出桌宠**。找不到小拉时，也可以通过托盘的彩色 **63** 图标打开围场。

## 更新与记录

应用内更新入口：**偏好设置 → 应用更新 → 检查更新**。

发布者上传新版更新文件后，可以在应用内下载，校验完成后自动重启。更新源连接失败时，可以稍后重试，或从夸克网盘、发行版页面手动下载新版。夸克分享用于手动下载，应用内更新继续使用程序已配置的发布源。

日记、任务、收藏、穿搭和自定义台词保存在当前 Windows 账户的固定目录：

`%LOCALAPPDATA%\GeorgeBeagle\UserData`

同一台电脑、同一个 Windows 账户下，更新或移动程序后会继续读取这些记录。可以通过 **偏好设置 → 打开记录文件夹** 找到它们。备份时先退出桌宠，再复制整个记录文件夹。

从旧内部版本升级时，可将新版程序放回旧文件夹运行一次，自动复制旧记录；也可以在 **偏好设置 → 导入旧版记录** 中选择旧文件夹。手动导入前会自动备份当前记录。

目前没有云同步，换电脑或 Windows 账户时需要搬动记录。

赛前提醒需要桌宠保持运行，隐身时不会弹出提醒。查看在线文章、视频或更新赛历需要网络；临时赛程调整请以官方信息为准。
