# 乔拉比格 · 桌面小拉

一只冷脸、爱被夸，偶尔会 werwerwerwer 的 Windows 桌宠。

以 George Russell 赛车元素和暹罗厘普比格犬二创形象为灵感，陪你工作、学习，也陪你关注比赛。

## 下载与使用

前往 [Releases 下载页面](https://github.com/Lena0509/george-beagle-releases/releases)。

首次使用请选择 **乔拉比格-Windows-v1.0-公开版.zip**，完整解压后，双击文件夹中的 `GeorgeBeagle.exe`。

请不要直接在压缩包里运行程序。

- 支持 Windows 10 / 11
- 需要 .NET Framework 4.8
- 无需安装 Python 或 Node.js

## 可以和小拉做什么

- **桌面互动**：摸摸、喂食、睡觉、拖动、T-pose 和柚子叶动作
- **衣橱换装**：搭配帽子、头盔、赛车服、短袖、卫衣和外套
- **小拉的车库**：选择历年赛车及部分特殊涂装
- **今日三件事**：记录当天想完成的三件小事
- **专注一圈**：用专注计时陪你完成任务
- **小拉的口袋**：收集和使用陪伴中的小物
- **陪伴日记**：留下心情、留言与陪伴记录
- **比赛周末**：查看赛程、设置提醒和应援穿搭
- **皇帝纪事**：通过赛道纪年与起居注，回看乔拉的故事、采访和官方影像
- **官方链接**：打开乔拉的官网、社媒和 GR63 Academy 网站

## 常用操作

| 操作 | 功能 |
| --- | --- |
| 单击小拉 | 摸摸互动 |
| 双击小拉 | T-pose |
| 按住并拖动 | 移动小拉 |
| 原地长按 | 柚子叶动作 |
| 右击小拉 | 打开菜单 |
| Shift + G + R | 隐身，再按一次召回 |

关闭围场窗口只会收起面板，小拉仍会留在桌面。

需要完全退出时，请在右键菜单或托盘菜单中选择 **退出桌宠**。

## 更新与记录

v1.0 起提供应用内更新入口：

**偏好设置 → 应用更新 → 检查更新**

发布新版后，可以在应用内下载更新，完成校验后自动重启。更新源连接失败时，可以稍后重试，或从 Releases 手动下载新版。

日记、任务、收藏、穿搭和自定义台词保存在当前 Windows 账户的固定目录：

`%LOCALAPPDATA%\GeorgeBeagle\UserData`

在同一台电脑、同一个 Windows 账户下，更新或移动程序后会继续读取这些记录。

可以在 **偏好设置 → 打开记录文件夹** 中找到它们。备份时，请先退出桌宠，再复制整个记录文件夹。

从旧内部版本升级时，可将新版程序放回旧文件夹运行一次，自动复制旧记录；也可以通过 **偏好设置 → 导入旧版记录** 选择旧文件夹。手动导入前会自动备份当前记录。

目前没有云同步，换电脑或 Windows 账户时需要搬动记录。
